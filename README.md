# Maxi Burguer — menú digital

Esta carpeta contiene una versión inicial del menú digital, optimizada para celular y lista para GitHub Pages.

## Publicarlo en GitHub Pages
1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio nuevo, por ejemplo: `maxi-burguer-menu`.
3. Sube `index.html` y la carpeta `assets`.
4. En el repositorio entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`.
7. Guarda. GitHub te mostrará la dirección pública del sitio.
8. Con esa dirección podemos generar el QR definitivo.

## Nota
Los precios de las bebidas no aparecen en las fotografías recibidas, por lo que quedaron como lista sin precio. También podemos ajustar cualquier nombre/precio que quieras corregir antes de publicarlo.
